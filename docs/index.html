Focus

A compact execution layer for focused work: one owner for session timing, useful local history, and integrations that pass context instead of creating parallel state.

SourceInstall preview

v1.7 preview
Platform

~/Applications/Focus.app

Engineering problem

Focus needs to support ordinary countdown sessions and open-ended work without letting Planner, Deadlock or UI refresh logic become competing owners of timer state.

Design

Focus owns the active session. Planner can provide calendar context; Deadlock can receive protection requests. Local history records what actually happened, including planned-versus-actual duration for calendar-started work.

Timer updates are adaptive rather than permanently running at high frequency when the UI does not need it.

Install

Requires Apple's Command Line Tools.

git clone https://github.com/ren-jop/focus.git
cd focus
./install.sh

Boundaries

Apple Calendar remains outside Focus. Planner owns planning context. Focus owns timing. Deadlock owns enforcement. That separation is more important than making the three apps appear monolithic.
