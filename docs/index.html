Focus

A compact execution layer for focus sessions: configurable timing, countdown or count-up behaviour, local history, calendar metadata and Deadlock integration.

Author
Ren Jopson
Status
v1.7 preview
Source
GitHub

What it does

Focus supports ordinary countdown sessions and open-ended count-up sessions that record actual elapsed work.

Focus, short-break and long-break durations are configurable, along with the cadence for long breaks.

Calendar-started sessions retain labels and planned duration so Planner can compare what was scheduled with what actually happened.

AI in this project

AI helps iterate on timer semantics, integration edge cases, low-overhead update behaviour and data-model changes. It is also part of the surrounding productivity workflow: turning work history and project context into useful summaries, plans and handoffs.
