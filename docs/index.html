Focus

A compact execution layer for focus sessions: configurable timing, count-up or countdown behaviour, local history, calendar metadata and Deadlock integration.

Author
Ren Jopson
Version
v1.7
Source
GitHub

What it does

Focus supports ordinary countdown sessions and open-ended count-up sessions that record actual elapsed work.

Calendar-started sessions retain labels and planned duration so Planner can compare what was scheduled with what actually happened.

AI in this project

AI helps iterate on timer semantics, integration edge cases, low-overhead update behaviour and data-model changes. It is also part of the surrounding productivity workflow: converting work history and project context into useful summaries, plans and handoffs.
