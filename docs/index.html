Focus

A small focus timer I made because I wanted something native, quick to start and easy to connect to the rest of my setup.

Why I made it

I wanted a timer that could handle both ordinary countdown sessions and open-ended work without becoming another large productivity app.

What it does

Focus owns the active timer and stores a small local history of completed work. Planner can start it with calendar context, and it can ask Deadlock to enable distraction blocking when needed.

What I deliberately left out

It does not try to become a calendar and it does not own blocking rules. Keeping those jobs separate has made the app easier to understand and debug.

Install

git clone https://github.com/ren-jop/focus.git
cd focus
./install.sh

Current state

The timer, local history and integrations are working as a preview build. I’m mostly interested in keeping it fast and reducing features that do not earn their place.
